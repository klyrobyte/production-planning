# Tinjauan Umum Panel Admin (Administrasi Sistem)

Modul **Pengelolaan Sistem** menyediakan akses menu khusus untuk peran **Super Admin** guna mengatur jalannya infrastruktur digital Sugity Production Planning, memantau integritas data, dan melihat riwayat aktivitas.

---

## Cakupan Pengelolaan Sistem

Sebagai gerbang administratif pusat, panel admin terbagi menjadi beberapa bagian fungsional:
1.  **User & Role Management**: Mengatur akun sistem dan membatasi hak akses berdasarkan peran.
2.  **Global Audit Trail Logs**: Memantau log pemanggilan API sistem untuk analisis keandalan dan keamanan.
3.  **Infrastruktur Fisik**: CRUD data unit pabrik (Plant/Factory) dan unit mesin produksi.
4.  **Tema Dinamis**: Konfigurasi warna UI portal tanpa memerlukan kompilasi ulang kode frontend.
