# Tinjauan Umum Perencanaan

Modul **Perencanaan Order** (`/orders`) disediakan khusus bagi peran **Planner** untuk mengelola data permintaan produksi jangka menengah dan panjang, merinci daftar part cetak injeksi, dan memetakan kode pesanan dari pelanggan luar.

---

## Fitur Utama Perencanaan

Halaman ini mencakup tiga fungsi penting berikut:
1.  **Pengunggahan Forecast**: Mengimpor data permintaan model part dari file spreadsheet secara bulk.
2.  **Part Master**: Mengelola properti spesifikasi part cetak, termasuk cycle time standar dan cavity mold yang digunakan.
3.  **Order Conversion**: Menerjemahkan kode part eksternal pelanggan ke penamaan part internal Sugity (Sebango).

---

*Untuk mempelajari cara mengimpor berkas rencana kerja bulanan, buka halaman [Unggah Berkas Forecast](./upload-forecast.md).*
